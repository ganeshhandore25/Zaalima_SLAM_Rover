# Autonomous SLAM-Inspired Occupancy Mapping Rover

## Project Overview
This project focuses on developing an Arduino-based rover that measures distances using an ultrasonic sensor mounted on a servo motor. The rover will scan its surroundings, detect obstacles, and collect distance measurements for occupancy mapping.

## Hardware Components
- Arduino Uno R3
- L293D motor driver
- Two DC motors
- HC-SR04 ultrasonic sensor
- Servo motor
- Breadboard and connecting wires
- Motor power supply

## Project Progress
